\begin{hintblock}
The conduct and results of the test shall be summarized to include the following information:
\begin{enumerate}
  \item Date(s) the Test Plan was conducted, test operator(s), equipment number (incl.\ calibration due date), material lot(s) used, as appropriate.
  \item Description of how the Test Plan was performed.
  \item Summary of actual performance compared to the acceptance criteria and any unexpected results.
  \item Appropriate references to all records or data used to explain results or demonstrate compliance to the acceptance criteria.
\end{enumerate}
